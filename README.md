# ПРОТЭК — новая версия сайта

Современная версия pro-tek.pro на **реальных данных действующего сайта**: логотип, фирменные
цвета, меню, дерево каталога, товары с фотографиями, ценами и наличием по складам.
Ничего не выдумано — всё выгружено с сайта, источник каждого блока указан ниже.

## Как посмотреть

Простой способ — открыть `index.html` двойным кликом.

Полноценный (работают ссылки с параметрами, например карточка товара):

```powershell
powershell -ExecutionPolicy Bypass -File ".\tools\serve.ps1"
```

затем открыть <http://localhost:8765/>. Остановить — Ctrl+C.

## Честно о полноте данных

Это ограничения **исходного сайта**, а не выгрузки:

- **Фотографий у товара — ровно одна.** Галерей на pro-tek.pro нет ни у одного товара.
  Требование «минимум 4 фото» отсюда закрыть невозможно — нужны даташиты производителей.
- **У 49 товаров из 873 фото нет вообще** — сайт отдаёт заглушку. В концепте такие позиции
  честно помечены «Фото уточняется», чужая картинка не подставляется.
- **Характеристики заполнены у 34 товаров из 873** (около 4%). У остальных на сайте пусто.
- **Габаритных чертежей, видеообзоров и 3D нет** ни у одной карточки.
- Цена у 68 позиций — «по запросу», так на сайте.

## Что работает

Мега-меню каталога, живой поиск с подсказками, фильтр по наличию в конкретном городе,
выбор города в шапке, корзина с сохранением между сессиями, избранное, тёмная тема,
адаптив до мобильных.

## Структура

```
assets/css/style.css        дизайн-система на фирменных цветах
assets/js/data.js           каталог (генерируется, вручную не править)
assets/js/app.js            шапка, меню, поиск, корзина, карточки
assets/img/logo.png         логотип с сайта
assets/img/cat/             иконки разделов с сайта
assets/img/products/        фото для списков (7,5 МБ)
assets/img/products-lg/     полноразмерные фото (207 МБ)
_source/                    сырая выгрузка, нужна для пересборки data.js
tools/                      скрипты выгрузки и сборки
```

## Пересобрать данные

```powershell
powershell -ExecutionPolicy Bypass -File ".\tools\extract-tree.ps1"      # дерево каталога
powershell -ExecutionPolicy Bypass -File ".\tools\extract-catalog.ps1"   # товары и фото
powershell -ExecutionPolicy Bypass -File ".\tools\extract-details.ps1"   # характеристики
powershell -ExecutionPolicy Bypass -File ".\tools\build-data.ps1"        # сборка data.js
```

Сайт pro-tek.pro закрыт для зарубежных IP — при включённом VPN скрипты не достучатся.
Нужно либо отключить VPN, либо добавить `pro-tek.pro` в исключения (split tunneling).

## Что это не

Формы не отправляются, оформление заказа показывает уведомление. Цены и остатки —
на момент выгрузки, не живые. Для запуска нужна интеграция с вашей учётной системой.
