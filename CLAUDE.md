# CLAUDE.md

Указания для Claude Code при работе с этим репозиторием.

## Что это за проект

Концепт новой версии сайта pro-tek.pro (ООО «ПРОТЭК», Новосибирск — оптовые поставки
систем безопасности). Статический сайт без сборки и зависимостей: чистые HTML, CSS и JS.
Открывается двойным кликом по `index.html`, но полноценно — только через локальный сервер,
потому что Chrome по `file://` не передаёт параметры адреса (`?id=`, `?cat=`).

**Главный принцип проекта: никаких выдуманных данных.** Товары, цены, остатки, тексты,
логотипы и контакты выгружены с действующего сайта или с сайтов производителей. Если данных
нет — так и показываем («Фото уточняется»), а не подставляем правдоподобную заглушку.
Каждая характеристика в карточке подписана источником.

## Команды

```powershell
# просмотр сайта
powershell -ExecutionPolicy Bypass -File ".\tools\serve.ps1"        # http://localhost:8765

# полная пересборка данных (по порядку)
powershell -ExecutionPolicy Bypass -File ".\tools\extract-tree.ps1"      # дерево каталога -> _source\tree.json
powershell -ExecutionPolicy Bypass -File ".\tools\extract-catalog.ps1"   # товары и фото -> _source\catalog.json
powershell -ExecutionPolicy Bypass -File ".\tools\extract-details.ps1"   # характеристики -> _source\details.json
powershell -ExecutionPolicy Bypass -File ".\tools\extract-brands.ps1"    # логотипы брендов -> _source\brands.json
powershell -ExecutionPolicy Bypass -File ".\tools\enrich-vendors.ps1" -Brands "Промрукав"   # данные производителей
powershell -ExecutionPolicy Bypass -File ".\tools\build-data.ps1"        # всё вместе -> assets\js\data.js

# вырезка товара без фона для подложек
powershell -ExecutionPolicy Bypass -File ".\tools\make-cutouts.ps1" -Ids "81595,14975"
```

## Архитектура

Данные отделены от представления. Скрипты в `tools\` выгружают сырьё в `_source\*.json`,
`build-data.ps1` собирает из них единственный файл `assets\js\data.js`, а страницы читают
только его.

```
assets/js/data.js    ГЕНЕРИРУЕТСЯ — вручную не править, правки затрутся
assets/js/app.js     шапка, мега-меню, поиск, корзина, карточка товара, характеристики
assets/css/style.css вся вёрстка, дизайн-токены в :root
_source/             сырая выгрузка, нужна для пересборки data.js
tools/               скрипты выгрузки и сборки
```

### Что лежит в data.js

`CITIES` — шесть городов складов, порядок важен: поле `s` у товара это массив 0/1 в этом же порядке.
`MENU` — верхнее меню, снимается разбором `_source\home.html`.
`CATEGORIES` — 22 раздела, у каждого `sub[]` и списки `ids`.
`PRODUCTS` — 873 товара. Поля короткие ради размера файла:
`n` название, `b` бренд, `p` цена (null = по запросу), `img` карточное фото, `big` крупное,
`s` наличие по городам, `art` артикул производителя, `sp` характеристики с сайта,
`vsp` характеристики с сайта производителя, `vimg` его фотографии, `av` наличие со сроками.
`BRANDS` / `BLOGO` — 234 бренда с логотипами.
`PMAP` — индекс товаров по id.

### Характеристики: три источника

`allSpecsOf(p)` в `app.js` собирает параметры и помечает происхождение:

1. `каталог Протэк` — из `p.sp`, заполнено лишь у 34 товаров из 873;
2. `сайт <бренд>` — из `p.vsp`, добыто `enrich-vendors.ps1` со строгой сверкой артикула;
3. `из наименования` — разбор названия правилами `SPEC_RULES`, например из
   `TC-C32QN I3/E/Y/2.8mm/V5.1 2Мп Уличная цилиндрическая` достаются разрешение,
   фокус, исполнение и форм-фактор.

Правило: **не добавлять четвёртый источник в виде «правдоподобных» значений.**

## Особенности окружения

**PowerShell 5.1 и кириллица.** Файлы `.ps1` с русским текстом обязательно сохранять в
UTF-8 **с BOM**, иначе PowerShell читает их как ANSI и падает с `ParserError`. После любой
правки скрипта:

```powershell
$t=[IO.File]::ReadAllText($f,[Text.UTF8Encoding]::new($false)); [IO.File]::WriteAllText($f,$t,[Text.UTF8Encoding]::new($true))
$err=$null; [void][System.Management.Automation.Language.Parser]::ParseFile($f,[ref]$null,[ref]$err)
```

Зарезервированные имена переменных, которые нельзя использовать: `$home`, `$pid`, `$host`, `$input`.

**Доступ к pro-tek.pro.** Сайт закрыт для зарубежных IP. При включённом VPN скрипты выгрузки
не достучатся — нужно отключить VPN или добавить `pro-tek.pro` в исключения (split tunneling).
То же касается `iek.ru`, `dkc.ru`, `smartec-security.com`.

**Проверка вёрстки.** Windows не даёт окну Chrome быть уже ~500 пикселей, поэтому
`--window-size=390` даёт ложный результат. Настоящая мобильная ширина проверяется страницей
с `<iframe style="width:390px">`.

## Известные ограничения данных

Это ограничения источника, а не выгрузки — их не надо «чинить» подстановкой:

- фотография у товара **одна**, галерей на pro-tek.pro нет ни у одного товара;
- у 49 товаров из 873 фото нет вовсе, сайт отдаёт заглушку `no-photo`;
- характеристики заполнены у 34 товаров (около 4%);
- габаритных чертежей, видеообзоров и 3D-моделей нет ни у одной карточки;
- у 68 позиций цена «по запросу»;
- «крупное» фото иногда мельче карточного — `build-data.ps1` выбирает больший файл.

## Стиль кода

Комментарии и весь текст интерфейса — по-русски. Цвета только через токены из `:root`
(`--brand: #005AAB`, `--accent: #E63244`), фирменные значения взяты из CSS действующего сайта.
В сетках на узких экранах использовать `minmax(0, 1fr)`, иначе колонки не сжимаются и
страница уезжает по горизонтали. Высоту блоков с картинками задавать явно: от `aspect-ratio`
не считаются проценты `max-height`, и блок растягивается под снимок.
